О проекте
3D Solar System — учебное приложение для наглядной демонстрации законов небесной механики. Программа моделирует гравитационное взаимодействие планет, позволяет запускать кометы, создавать чёрные дыры и наблюдать физические процессы в реальном времени.
Проект разработан с применением принципов ООП и паттернов проектирования, что обеспечивает модульность, тестируемость и возможность расширения функционала.
   Возможности
   Физическая симуляция
Реалистичная модель гравитации по закону Ньютона
Численное интегрирование методом Верле
Обнаружение и обработка столкновений
Орбитальное движение с расчётом начальных скоростей
   Интерактивные объекты
Планеты: 8 планет Солнечной системы с текстурами и орбитами
Кометы: запуск к любой планете с визуализацией хвоста и свечения
Чёрные дыры: притяжение объектов, аккреционный диск, частицы
Астероидный пояс: 400+ астероидов между Марсом и Юпитером
Звёздное небо: 4500+ звёзд с параллакс-эффектом
   Интерфейс и управление
Свободная камера с управлением мышью и клавиатурой
Режим слежения за кометой
Информационная HUD-панель со статистикой
Встроенная SQL-консоль для динамических команд
   Работа с данными
Автоматическая инициализация SQLite-базы
Приём команд управления через таблицу SOLAR_COMMANDS
Логгирование событий в таблицу SIMULATION_LOGS
Периодический опрос БД без блокировки основного потока
