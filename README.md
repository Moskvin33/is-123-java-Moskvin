## Возможности

### Физическая модель
- Реалистичная гравитация — закон всемирного тяготения Ньютона
- Метод Верле — численное интегрирование для точных орбит
- Орбитальное движение с начальными скоростями для стабильных орбит
- Обработка столкновений и слияний небесных тел
- Специальная логика для чёрных дыр с горизонтом событий

### Визуальные эффекты
- Атмосферы планет — полупрозрачные оболочки с рассеиванием света
- Кометы — градиентные хвосты, динамическое свечение, частицы
- Чёрные дыры — аккреционные диски, гравитационное гало, вращающиеся частицы
- Взрывы планет — анимация фрагментов, ударные волны, вспышки
- Звёздное небо — многослойный фон с параллаксом (4500+ звёзд)
- Кольца Сатурна — прозрачные текстурированные кольца со свечением
- Астероидные пояса — 400+ астероидов с индивидуальными орбитами

### Управление через базу данных
- SQLite база данных для динамических команд управления
- SQL-интерфейс для создания и удаления объектов в реальном времени
- Автоматический опрос команд каждые 2 секунды
- Логирование событий симуляции в таблицу SIMULATION_LOGS

## Управление

### Клавиатура
| Клавиша | Действие |
|---------|----------|
| WASD | Полёт камеры вперёд/назад/влево/вправо |
| Q/E | Подъём / Спуск камеры |
| ПКМ + мышь | Вращение камеры вокруг сцены |
| C | Следовать за кометой (если активна) |
| F | Вернуться в свободный режим камеры |
| 0-8 | Запустить комету к объекту (0=Солнце, 3=Земля...) |
| B | Создать чёрную дыру |
| ` (backtick) | Открыть SQL-консоль |
| Пробел | Пауза / Продолжить симуляцию |
| +/- | Ускорить / Замедлить время (0.1x - 8.0x) |
| X | Сбросить систему к начальному состоянию |
| R | Сбросить камеру в исходную позицию |

## Установка

### Требования
- Java 17 или выше
- Maven 3.8+
- Графическая среда с поддержкой JavaFX

### Сборка проекта

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/solar-system-3d.git
cd solar-system-3d

# Сборка проекта
mvn clean package

# Запуск через Maven (рекомендуется)
mvn javafx:run
